# Robotics WS — Практические работы

Репозиторий для выполнения практических работ по робототехнике.
Каждой практической работе создана отдельная ветка имеющая примерно следующую структуру
## 📁 Структура репозитория

```bash
robotics_ws/
├── .github/workflows/    # CI/CD пайплайны для автоматической проверки
├── evidence/             # Результаты выполнения практических работ
│   ├── prX/             # Практическая работа №X
├── src/                  # Исходный код
├── install/              # Скомпилированные пакеты
├── build/                # Промежуточные файлы сборки
└── log/                  # Логи
```

##  Ветвление

Каждая практическая работа выполняется в **отдельной ветке**:

| Ветка | Назначение |
|-------|-----------|
| `pr01` | Практическая работа №1(Основная ветка, содержит стабильную версию) |
| `pr02` | Практическая работа №2 |
| `prXX` | Практическая работа №X | 

### Правила работы с ветками

1. **Создание ветки для новой работы:**
   ```bash
   git checkout pr01
   git pull origin pr01
   git checkout -b prXX  # где XX - номер работы
   ```

2. **Структура папки evidence:**
   - Каждая ветка содержит свою папку в `evidence/prXX/`
   - Файлы из предыдущих работ **не копируются** автоматически
   - При необходимости можно перенести файлы из предыдущих работ

3. **Переключение между работами:**
   ```bash
   git checkout pr01  # переключиться на первую работу
   git checkout pr02  # переключиться на вторую работу
   ```

## 🤖 Автоматическая проверка (CI/CD)

При push в ветку `pr*` запускается автоматическая проверка, необходимая для нынешней практической работы:

1. **Валидация JSON** — проверка `environment.json`
2. **Проверка файлов** — наличие и непустота обязательных файлов
3. **Специфичные тесты** — зависят от номера работы
